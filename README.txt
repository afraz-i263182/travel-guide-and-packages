TRAVEL POSTCARD WEBSITE
=======================

PROJECT FILES
-------------
index.html          Home page
Destinations.html   Explore Destinations page (filename: destinations.html)
travel-guide.html   Travel Guide and Tips page
packages.html       Explore Packages and Booking page
style.css           Shared cream-and-green theme and responsive styling
site.js             Browser-side filters and booking inquiry preview
images/             Local optimized scenic image assets

HOW TO OPEN
-----------
1. Extract the ZIP file into a folder.
2. Keep all four HTML pages, style.css, site.js and the images folder together.
3. Open index.html in a modern web browser.
4. Use the navigation bar to move between pages.

IMPORTANT NOTES
---------------
- The site uses plain HTML, CSS and a small amount of JavaScript. No framework or
  installation is required.
- The scenic images are AI-generated illustrations for visual presentation; they
  are not documentary photographs of the exact named destinations.
- Package names, durations and prices on packages.html are reproduced from the
  original Hunza page supplied for the project. Confirm real availability,
  inclusions and prices with the travel provider before making payment.
- The booking form is a front-end demonstration only. It validates the fields
  and displays a local inquiry preview; it does not send or store personal data.
  A real booking system requires a secure back end or a trusted form service.
